## Project Icon

| Asset | Path | Recommended use |
|-------|------|-----------------|
| Slay Check icon | `assets/slay-check-icon.png` | README hero image, LinkedIn featured section, GitHub/social previews, marketplace listings |

Use the icon with descriptive alt text, for example:

```html
<img src="assets/slay-check-icon.png" alt="Slay Check icon" width="160" />
```

## Usage Notes

- Keep the icon visually clear by placing it on a plain or lightly textured background.
- Use `Slay Check icon` as the default alt text in documentation.
- Prefer the repository asset path (`assets/slay-check-icon.png`) so links continue to work on GitHub.
- Avoid stretching or recoloring the icon in docs or promotional material.

## Suggested Social Copy

For LinkedIn or other project showcases, pair the icon with a short title such as:

> Slay Check - AI code reviews for GitHub Actions and local development

And a short description such as:

> Open-source Python tool that runs AI-powered code review on GitHub pull requests and local git changes, with support for OpenAI, Anthropic, Google Gemini, Perplexity, Ollama, GitHub Models, and custom HTTP providers.
