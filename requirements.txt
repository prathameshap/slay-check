## Installation

### From Source
```bash
git clone https://github.com/YOUR_USERNAME/slay-check.git
cd slay-check
pip install -e .
```

### From GitHub
```bash
pip install git+https://github.com/YOUR_USERNAME/slay-check.git
```

### Development Installation
```bash
pip install -e ".[dev]"
```

## Usage

### CLI
```bash
slay-check --help
slay-check review --pr 123 --repo owner/repo
slay-check config init
```

### Python API
```python
from slay_check import SlayCheck

checker = SlayCheck()
result = checker.review_pull_request("owner/repo", 123)
print(result.score)
```

## Configuration

Create `slay-check.yaml` in your repository root:

```yaml
ai_provider: openai
ai_token: "your-token"
review_criteria:
  analyze_problem: true
  algorithm_analysis: true
  best_approaches: true
  complexity_analysis: true
  risk_assessment: true
  security_review: true
  performance_review: true
```

## GitHub Actions

```yaml
name: Slay Check
on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  slay-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - name: Install Slay Check
        run: pip install git+https://github.com/YOUR_USERNAME/slay-check.git
      - name: Run Slay Check
        env:
          SLAY_CHECK_AI_TOKEN: ${{ secrets.SLAY_CHECK_AI_TOKEN }}
          SLAY_CHECK_GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: slay-check review --pr ${{ github.event.pull_request.number }} --repo ${{ github.repository }}
```
