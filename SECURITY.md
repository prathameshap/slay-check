# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability, please report it via a [GitHub Security Advisory](https://github.com/prathameshap/slay-check/security/advisories/new).

Include as much detail as you can: what you found, how to reproduce it, and the potential impact.

### What to expect

This is a solo-maintained open-source project. I will do my best to:

- Acknowledge your report in a reasonable timeframe
- Investigate and assess the impact
- Coordinate a fix and disclosure when possible

Please understand there are no guaranteed response times. If you haven't heard back after a while, feel free to follow up on the advisory.

### Out of scope

- Issues in third-party AI provider APIs (OpenAI, Anthropic, Google, etc.) — report to those vendors directly.
- General dependency vulnerabilities — please open a regular issue instead.

Thank you for helping keep Slay Check safe.
