# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability, please report it by one of the following means:

1. **Preferred**: Open a [GitHub Security Advisory](https://github.com/prathameshap/slay-check/security/advisories/new) (if you have access).
2. **Alternative**: Email the maintainers (see [README](README.md) for contact) with:
   - Description of the vulnerability and steps to reproduce
   - Impact assessment
   - Suggested fix (if any)

We will acknowledge your report within **5 business days** and will send a more detailed response within **10 business days**.

### What to expect

- We will confirm the vulnerability and determine the impact.
- We will work on a fix and coordinate disclosure (including crediting you if you wish).
- We ask that you do not disclose the issue publicly until we have released a fix or agreed on a disclosure timeline.

### Out of scope

- Issues in third-party AI provider APIs (OpenAI, Anthropic, Google) — report to those vendors.
- General dependency vulnerabilities — we rely on Dependabot and regular updates; prefer opening an issue for outdated dependencies.

Thank you for helping keep Slay Check and our users safe.
