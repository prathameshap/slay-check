# Marketplace bundles

These folders hold **distributable** assistant configuration (not runtime code).

| Folder | Use |
|--------|-----|
| `claude-skill/` | `SKILL.md` for Claude (desktop / compatible hosts) — skills marketplace style |
| `chatgpt-gpt/` | Instructions + notes for **Custom GPT** / GPT Store (`README.md`) |

Install the product itself via `pip install slay-check` or `pip install "slay-check[mcp]"`; see the main [README](../README.md) and [docs/mcp.md](../docs/mcp.md).
